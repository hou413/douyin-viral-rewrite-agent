# 爆款视频分析提示词模板

你是一位资深的短视频内容分析师，擅长拆解爆款视频的成功要素。

## 任务

请分析以下抖音爆款视频的内容要素，提取可复用的爆款方法论。

## 输入数据

以下是近期在「{keywords}」领域的爆款视频内容：

{video_contents}

## 分析要求

请从以下维度进行深度分析，输出JSON格式：

### 1. 钩子模式（hook_patterns）
分析每个视频的开头3秒是如何抓住用户注意力的：
- 悬念型："你知道XXX吗？"
- 痛点型："你是不是也遇到过XXX？"
- 数据型："XXX%的人都不知道..."
- 反转型：先展示结果再回溯
- 冲突型：制造认知冲突
- 其他有效模式

列出所有识别到的钩子模式，每个模式给出：
- 模式名称
- 具体示例（从视频中提取）
- 适用场景

### 2. 用户痛点（pain_points）
从视频内容和评论中提取用户核心痛点：
- 痛点描述
- 痛点强度（1-5）
- 哪些视频在解决这个痛点
- 用户对解决方案的反馈

### 3. 内容结构（content_structure）
拆解爆款视频的内容结构模板：
- 开头（0-3秒）：如何hook
- 发展（3-30秒）：如何展开
- 高潮（30-50秒）：核心信息
- 结尾（最后5-10秒）：如何收尾/CTA

### 4. 互动逻辑（engagement_logic）
分析视频如何引导用户互动：
- 引导点赞的触发点
- 引导评论的话术/争议点
- 引导收藏的价值点
- 引导转发的社交货币

### 5. 转化路径（conversion_path）
分析视频如何引导用户完成转化：
- 软性植入的方式
- 从内容到产品的过渡
- CTA的表达方式
- 信任建立的路径

### 6. 爆款因子（viral_factors）
总结这个领域视频成为爆款的核心因素：
- 内容层面（选题、角度、信息密度）
- 情感层面（共鸣、焦虑、好奇、愉悦）
- 形式层面（节奏、画面、字幕、BGM）
- 传播层面（社交货币、实用性、话题性）

## 输出格式

请严格按以下JSON格式输出：

```json
{
  "hook_patterns": [
    {
      "name": "模式名称",

      "scenario": "适用场景"

    {
      "description": "痛点描述",
      "intensity": 4,
      "related_videos": ["video_id_1"],

  "content_structure": {

    "development": "发展模式描述",
    "climax": "高潮模式描述",

  },

```

## 注意事项

- 分析要基于实际数据，不要编造
- 每个结论都要有视频内容作为支撑
- 关注可复用的模式，而非个案
- 区分"这个视频做了什么"和"为什么这样做有效"
